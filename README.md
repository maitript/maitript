## Featured projects

### [Medigate](https://github.com/maitript/medigate)
Healthcare API platform — multi-service backend with JWT-secured gateway, sync **gRPC** billing, **Kafka** analytics, Dockerized services, and **AWS CDK → LocalStack** (ECS, RDS, MSK). Built with **Java / Spring Boot**.

### [Counterfeit Product & Fake Review Detection](https://github.com/maitript/Counterfeit-Product-and-Fake-Review-Detection)
Dual-signal e-commerce authenticity: **YOLOv7** brand-logo detection (Flickr Logos 27) + a designed **fake-review NLP** path (TF–IDF / BERT-style models, OpSpam & Amazon corpora).

### [Anomaly Detection using QBM](https://github.com/maitript/Anomaly-Detection-using-QBM)
Classical vs quantum-annealing **RBMs** on network intrusion flows (ISCX IDS 2012), with Tabu / **D-Wave** sampling via PyQUBO + Ocean SDK.

### [Car Theft Detection (Parking)](https://github.com/maitript/Car-theft-detection-Parking)
CCTV motion analysis in marked parking bays + **barcode** access control to flag unauthorized vehicle movement (OpenCV, pyzbar).
